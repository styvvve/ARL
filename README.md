# Agent Reliability Lab (ARL)

Assistant de notes **locales** qui recherche et lit des notes, répond en s'appuyant sur elles,
utilise des outils contrôlés et fournit des réponses **vérifiables**. Fil rouge du cours
« Agents d'IA : comprendre, construire, évaluer, sécuriser ».

L'état courant du projet est décrit dans `JALON.md`.

## Installation
```bash
python -m venv .venv
source .venv/bin/activate          # Windows : .venv\Scripts\activate
pip install -e .
arl diagnostic
```
